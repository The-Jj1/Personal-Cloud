# Personal-Cloud ☁️

Система за съхранение и управление на файлове (Дипломен проект).

## 📋 Изисквания към проекта (Дипломно задание)
*   **Тема:** Файлов мениджър (Personal Cloud).
*   **Обем:** Минимум 30 страници (54,000 символа).
*   **Технологии:** Web-базирана система (React, Node.js).
*   **Функционалност:** Upload/Download, Навигация в папки, Preview на файлове, Споделяне, Индикация за пространство.

---

## 🛠️ Предварителни изисквания
1.  **Node.js** (v18.0.0 или по-нова).
2.  **XAMPP** (инсталиран в `C:\xampp\`).
    *   След като отворите **XAMPP Control Panel**, трябва да натиснете бутоните **"Start"** срещу **Apache** и **MySQL**, докато имената им светнат в зелено.
    *   *Забележка:* Файлът `run.bat` ще се опита да направи това автоматично, но ако не успее, трябва да го направите ръчно.


---

## 🚀 Подготовка (изпълнява се веднъж)

1.  **Инсталиране на библиотеки за Сървъра:**
    ```bash
    npm install
    ```

2.  **Инсталиране на библиотеки за Клиента:**
    ```bash
    cd client
    npm install
    cd ..
    ```

3.  **Инициализация на Базата данни:**
    **ВАЖНО:** Първо стартирайте MySQL от XAMPP. След това изпълнете:
    ```bash
    node scripts/setup-db.js
    ```
    *Този скрипт ще създаде базата `personal_cloud` и необходимите таблици.*

## 🏃 Как да стартирате проекта

### Вариант А: Автоматично (Препоръчително за Windows)
Стартирайте файла **`run.bat`**. 
Той автоматично ще:
*   Опита да стартира XAMPP (Apache и MySQL).
*   Пусне Backend сървъра в минимизиран прозорец (`npm start`).
*   Пусне Frontend клиента в минимизиран прозорец (`npm run dev`).

### Вариант Б: Ръчно
1.  Стартирайте **MySQL** от XAMPP.
2.  **Backend:** В основната папка изпълнете `npm start`.
3.  **Frontend:** Влезте в папка `client` и изпълнете `npm run dev`.
